# Tessalume 1.2.0

Tessalume 1.2 把主题画廊、主题导入、个性化调节、诊断恢复、Codex 一句话创作和软件更新整理为一套完整的 Windows 便携主题工作台。

## 本次重点

- 全新的统一主界面、设置页、诊断页、首次启动引导和产品弹窗。
- 10 套同时支持亮色与暗色的 Template 1.0 内置旗舰主题。
- 首页横幅、左栏人物与聊天背景可按主题和 Codex 亮暗模式分别调节亮度、对比度、饱和度与不透明度，默认显示原图。
- 支持文件夹和 ZIP 主题导入，限制路径越界、链接条目、文件数量和解压体积。
- 可从软件内准备自包含的 Codex 创作者工作区，用一句角色需求启动研究、11 张素材规划、制作与校验流程。
- 默认开启官方 Release 更新检查，支持版本说明、下载进度、SHA-256 校验、旧版备份、进程外替换、失败保留和自动重启。
- 新增本机诊断、日志轮换、内置主题恢复、键盘快捷键、小屏幕适配和 Per-Monitor V2 DPI 支持。
- 开机自动启动默认关闭；主题应用不会未经确认关闭正在运行的 Codex。

## 升级说明

1.2 是首个内置自动更新器的版本。1.1 用户需要本次手动下载并替换原文件夹中的 `Tessalume.exe`；不要删除旁边的 `data/`、`themes/`、`Compatibility/` 或 `Templates/`。进入 1.2 后，后续正式版本可以直接在软件内更新。

## 下载与校验

Release 固定提供：

- `Tessalume.exe`
- `SHA256SUMS.txt`

当前构建面向 Windows x64，已经包含 .NET 运行时。EXE 暂无商业代码签名，首次运行可能出现 Microsoft Defender SmartScreen 提示，请只从本仓库 Release 下载并核对 SHA-256。

## 已知边界

- 主题运行依赖 Windows 版 Codex Desktop 的本机调试端口和页面结构。
- 自动更新依赖 GitHub 可访问性；检查失败不会修改当前版本。
- 高级第三方主题可以包含在 Codex 页面中运行的 `theme.js`；请只导入自己制作、由自己的 Codex 工作区生成或来源明确的主题包。
