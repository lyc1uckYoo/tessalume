## 后续维护规则

1. 不允许用同一张人物图通过滤镜兼任亮色、暗色或不同卡片。
2. 左栏人物脸部必须在 1280×820 与 1600×900 下清晰可见；调整遮罩时优先保护脸部，再单独增强菜单行底色。
3. 左侧任务卡只能位于标题下方阅读边栏，不得压住正文。
4. 右下两张卡保持同尺寸，并使用相反相位的浮动动画。
5. 顶部身份条保持在原生任务顶栏内，首页与任务页都应显示。
6. 新增素材后必须更新 `manifest.json`，未被清单引用的旧运行时图片应移出 `assets`。
