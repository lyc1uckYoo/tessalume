# 心 · 朝月孤城

`xin.moonfox-sovereign` 是一款 Tessalume 高级旗舰主题，以梦州岁主心月狐为核心。

## 2.0 专属聊天背景

- 2.1.6 参照秧秧主题校准人物视觉高度：亮暗背景均放大至 116%，同时将正文底层与渐变遮罩降至同级透明度。
- 亮色新增白玉云宫月台，暗色新增赤月梦州夜城，两张背景均为独立绘制。
- 背景只存在于中央消息正文列，并以单张粘性画面跟随阅读视窗；左右卡片与输出区域保持独立。
- 2.1.1 降低亮色正文与左栏的白玉遮罩强度，并为左栏任务行补充局部玻璃底。

## 2.1 朝月心珰

- 2.1.5 降低暗色聊天场景的双层深红遮罩强度，使心与赤月建筑更清晰，同时保留正文对比度。
- 2.1.4 将文件改动汇总卡及其文件行改为全透明，保留分隔线、增删数字、图标与操作按钮。
- 2.1.3 移除助手消息卡与用户气泡的底色和模糊层，让中央聊天背景完整显示，仅保留边框、符号与排版。
- 输入框左侧采用立绘胸前红玉与四向月轮结构重新设计，不再使用狐狸剪影。
- 红玉呼吸、月轮缓转与双侧流苏错峰摆动，组成独立的角色信物动效。

## 视觉结构

- 亮色首页：白玉云宫、朝月门、山水长卷与人形岁主。
- 暗色首页：赤月黑城、狐火与九尾狐神影，使用独立横幅而非滤镜复用。
- 左侧栏：亮暗模式分别使用独立角色肖像，项目以四种岁序心印区分层级。
- 任务页：标题下方放置人形岁主卡；右下角同时放置人形战斗卡与白狐本体卡，两张卡同规格、反向漂浮、错峰显影。
- 输入框：亮色为白玉纸面，暗色为黑漆红玉，文本、占位符和按钮始终保持可读。

## 自定义图片

所有图片位于 `assets/`。保持清单中的文件名即可替换：

- `hero-light.png` / `hero-dark.png`：首页横幅，建议 16:9，角色靠右并为左侧文案留白。
- `sidebar-light.png` / `sidebar-dark.png`：左栏竖图，建议 9:16，脸位于上半部且避免把主要五官放到文字区。
- `chat-light.png` / `chat-dark.png`：中央聊天正文背景，建议 16:9，人物置于最右侧并为中央文字留白。
- `task-oracle.png`：标题下方人形卡。
- `task-human.png` / `task-fox.png`：右下双动效卡，建议保持相同尺寸与构图密度。
- `memory-light.png` / `memory-dark.png`：左侧记忆档案横图。

修改图片或代码后需要重新导入或刷新本地主题库；高级主题脚本的信任与文件指纹绑定。
