# Tessalume 主题创作者工作区

## 用户体验目标

- 用户只需用一句自然语言说明作品和角色，例如：
  `请为《鸣潮》的椿制作一套 Tessalume 主题。`
- 对任何新主题，必须使用 `$author-tessalume-theme` Skill 完成研究、素材规划、
  脚手架、制作和校验，不凭记忆临时发明 Tessalume 结构。
- 角色研究和 11 张素材计划必须先展示给用户确认；确认后再生成图片和主题代码。

## 工作边界

- 这是便携创作者工作区，不是 Tessalume 应用源码仓库。
- 不要求 Git，不创建分支，不提交、不推送，也不运行 `一键构建EXE.ps1`。
- 新主题只创建在 `themes/<主题目录>/`，不得修改 `src/` 中的共享几何文件。
- 完成后运行 Skill 提供的两个校验脚本；校验通过后告诉用户在 Tessalume 中导入
  对应的 `themes/<主题目录>` 文件夹。
- 不加入远程图片、网络请求、本机绝对路径、账号信息或其他工作区之外的文件。

## 交付说明

- 明确区分：素材方案已确认、静态契约已通过、是否已在 Tessalume 中运行检查。
- 不声称未实际运行的视觉状态已经验收。
- 保留角色专属构图、纹样、组件和动效；模板只统一结构与几何。
