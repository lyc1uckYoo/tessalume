# Tessalume Creator Workspace

This marker tells the bundled `author-tessalume-theme` skill to use portable
creator mode. Themes are created under `themes/`, validated here, and imported
into Tessalume. This workspace does not build or modify the Tessalume app.

The machine-readable workspace and Template versions are stored in
`TESSALUME_CREATOR_WORKSPACE.json`. Tessalume may update managed tools and
guides after preserving a local backup, but never overwrites projects under
`themes/`.
