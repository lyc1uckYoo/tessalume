# 宠物开发项目

`pet-projects/<pet-id>` 是 Codex 制作和调整宠物的开发源空间。Tessalume 的“宠物画廊”只读取这里生成的候选动画，用于逐动作预览和审核。

开发项目与正式发布严格分开：

- 素材、关键帧、脚本与设计说明保存在 `pet-projects/<pet-id>`。
- 候选结果统一生成到项目自己的 `build/`；画廊会在文件稳定后自动刷新。
- 开发预览不能安装、更新、修复或卸载 Codex 宠物，也不会写入 `.codex\pets`。
- 用户可安装的正式包只位于 `pets/<pet-id>`，并继续接受 catalog、SHA-256 与构建门禁。
- 将候选晋升为正式包是单独的审核动作，预览或保存开发项目都不代表发布。

每个项目使用 `pet-project.json` 声明身份、协议、候选输出目录和完整动作预览。新增宠物时复制的是这套项目结构与契约，不是某个已发布宠物包。
