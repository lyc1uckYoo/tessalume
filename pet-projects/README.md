# 宠物开发项目

`pet-projects/<pet-id>` 是 Codex 制作和调整宠物的开发源空间，不属于 Tessalume 面向用户的宠物画廊资源。

开发项目与正式发布严格分开：

- 素材、关键帧、脚本与设计说明保存在 `pet-projects/<pet-id>`。
- 候选结果统一生成到项目自己的 `build/`，在项目内完成动作与 QA 审核。
- 用户可安装的正式包只位于 `pets/<pet-id>`，并继续接受 catalog、SHA-256 与构建门禁。
- 将候选晋升为正式包是单独的审核动作，预览或保存开发项目都不代表发布。
- 构建会把全部正式包带入 `dist/portable-win-x64/pets`；应用运行期间替换其中的完整正式包后，刷新画廊即可继续预览，无需重新构建 EXE。

每个项目使用 `pet-project.json` 声明身份、协议、候选输出目录和完整动作预览。新增宠物时复制的是这套项目结构与契约，不是某个已发布宠物包；面向用户的预览与安装始终使用 `pets/<pet-id>` 这一条正式资源链路。
