# 参考资料说明

本目录只用于身份核对、动作研究和画风对照，不会直接进入最终图集构建。正式身份仍以 `../assets/identity/flying-snowfluff-master.png` 为唯一母版。

- `canonical/`：早期官方像素图集，用于核对部件、状态语义和原始运动规律，不限定当前画风。
- `official/`：当前只保留官方墨镜形态；它不能替代默认正常眼睛。
- `studies/`：从正式素材整理的正面放大图、身份板、姿势板和墨镜放大图，便于观察小尺寸细节。
- `style/`：用户认可的平滑非像素表现方向，只约束观感，不覆盖身份母版。

添加新参考时必须放进对应类别，并在需要时同步更新 `design/character-bible.md`；不要把临时截图、候选输出或 ImageGen 中间图堆到这里。
