# 飞行雪绒 V1 最终动作复盘

## 结论

飞行雪绒 V1 已经成为本宠物项目的正式图集，并完成用户实时预览验收。它由 56 张透明关键姿势、2 张工作态翼链修复层、1 张减少动态效果中立帧、确定性的头部／质心注册、闭环编排和状态语义提示构成。本次正式精修让待机全身参与微循环，补齐工作态翼链，理顺等待输入与完成动作顺序，并提高全部开发预览的播放节奏；Codex v2 协议帧数仍固定为 74 格。

最终版九个普通动作的头部加速度全部低于原始像素素材；360° 环视则在真正改变视角的前提下，把上一安装版的头部加速度从 `4.440` 降到 `1.158`，最低相邻轮廓 IoU 从 `0.578` 提高到 `0.683`。向右移动的动作能量从上一版 `0.178` 提高到 `0.197`，同时头部步进从 `2.006px` 降到 `1.085px`。

## 本次正式精修

- 待机：从固定身体只换脸改为六个完整姿势参与，翼链、编发和身体都有克制的微循环。
- 左右移动：保留 8 个真实飞行姿势，移除末帧过长停顿，持续移动不再像突然刹停。
- 挥手／触屏：强化招呼、前探、接触和回位的触屏轨迹，四帧语义均可独立辨认。
- 跳跃：纵向质心跨度提高到 `12.51px`，蓄力、升空顶点和着陆明确分层。
- 阻塞：八帧全程保留故障徽记，低动态首帧也能直接读出阻塞状态。
- 等待输入：恢复 `听见 → 倾听 → 指示 → 邀请 → 等待 → 提醒` 的自然源顺序，并稳定头部锚点。
- 正在工作：补回第 2、4 帧缺失的左侧翼链，加入控制台扫描与加载反馈，同时降低头部漂移。
- 完成待看：启用原先遗漏的通知首帧，六个源姿势各用一次，并重排纸飞机轨迹；完成徽记保持全程可读，墨镜仍只出现一帧。
- 360° 环视：16 个真实方向格保持不变，仅将开发预览加快到约 `11.11 FPS`。
