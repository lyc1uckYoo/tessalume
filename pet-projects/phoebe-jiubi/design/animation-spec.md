# 菲比啾比动作规范

## 总体节奏

- 预览以 80–140 ms 的主要节拍为主，明确的落地、听候和完成姿势可短暂保持 160–220 ms。
- 每行关键帧与图集槽位一一对应；不通过额外补间 GIF 伪装实际宠物帧数。
- 每个动作都要有帽檐或长发的次级运动，但幅度不越过 192×208 安全边距。
- 性格反差是“一本正经的脸配上有点唐的小身体”：眼睛先呆半拍，短腿或小手才慌忙跟上；不是持续疯闹，也不是刻意摆拍卖萌。

## 状态设计

- `idle`（6 动画帧 + 1 neutral）：腹部呼吸、眼睛轻眨、脚尖换重心，帽檐慢半拍回弹。安静但身体不能像贴图。
- `move-right / move-left`（各 8）：大帽子和脑袋以 10–15° 低姿态先冲，极短双腿在下方慌忙追赶；采用“接触—压低—经过—腾空”×2 的完整两步循环。双手始终并拢抱紧胸前手杖，形成一个固定、清楚的手部团块，不做成人跑步式摆臂。帽檐与长发延迟半拍回弹，腾空不能靠缩放人物伪造。左右两行独立绘制，必须保持发夹、蝴蝶结和手杖的物理侧别。
- `wave-touch`（4）：先伸错一只手去扶帽檐，反应半拍后才用另一只黑手套快速挥手；第 0 帧已经抬手，语义立即可读。
- `jump`（5）：蹲压让帽檐盖住一小截眼睛，快速弹起，空中被帽檐短暂盖眼，发尾上扬，落地略站不稳后软回弹。
- `blocked`（8）：先一惊，帽檐滑到眼前，双手去扶却慢了一拍；蹲低后若无其事地僵住，再从帽檐下偷偷露眼。无泪滴、叉号或文字。
- `needs-input`（6）：身体向屏幕外探，手贴耳侧倾听，随后摊开小手做邀请，再回到期待姿态。
- `running`（6）：不是奔跑；保持已验收的紧凑盘腿坐姿，将空白笔记本稳定放在膝上。两只黑手套分居键盘左右键区并始终接触按键，以 A/B 前后落键、轻微对向肘部弯曲和专注视线形成自然连续打字循环；手杖收在身体物理右侧，不参与动作。
- `ready`（6）：从专注姿势收杖，抱在胸前，踮脚抬头，轻轻挺胸并眨眼；得意定格时脚下一晃，又若无其事站好。无剪贴板、纸张或庆祝文字。
- `gaze-upper/lower`（16）：眼睛先转，脸与帽子轻跟，长发与蝴蝶结滞后；脚底锚点稳定。方向必须反映空间转向，不能只是整张贴图旋转。

## 动作辨识门槛

- 以 192×208 单帧缩略图查看时，第 0 帧能分辨九种状态。
- 去掉眼睛和嘴巴后，仅凭轮廓和手部姿势仍能区分挥手、跳跃、受阻、等待、工作和完成。
- 循环末帧到首帧不出现主体横跳、帽檐瞬移、手杖换手或瞳孔跳位。
