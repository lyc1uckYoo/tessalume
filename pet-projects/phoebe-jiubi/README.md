# 菲比啾比开发项目

这是 Tessalume 中的 Codex v2 宠物开发源项目。目标是保留社区喜爱的“大头、巨眼、短手短脚”菲比啾比气质，同时重新设计一套属于本项目的纸偶珐琅画风和状态动作。

## 开发边界

- 用户参考图只用于比例、气质和身份锚点。
- 开源桌宠只用于核对协议与制作流程，不直接复制图集、逐帧动作或视觉资产。
- 候选输出位于 `build/final-motion-candidate/`，仅用于项目内审核。
- 用户已于 2026-08-19 明确验收正式版；发布包位于 `pets/phoebe-jiubi`，并由统一宠物画廊负责预览与安装。

## 视觉关键词

大饼头、紫色玻璃眼、软帽檐、豆子手脚、厚可可描边、奶金与湖蓝、哑光纸偶边缘、帽子和长发的弹性滞后。
